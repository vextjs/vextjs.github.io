      VextJS

      VextJS 是面向 API 与服务端渲染 React 页面的 AI-first Node.js 全栈应用框架。约定、脚手架、类型契约、OpenAPI 与机器可读文档为 AI 编程助手提供明确输入。AI-first 不代表内置 LLM、Agent、RAG 系统或推理 runtime。

      Hot Reload Pipeline

      三段式后端热重载加前端重建，让开发反馈更紧。

      Vext 会按变更边界选择不同策略：能热替换的直接替换，客户端文件变化时重建前端资源，触及运行时边界时再冷启动。

      T1 / code

      修改已有后端文件

      命中 src/routes/ 等 soft 范围内的已有文件修改时，通常定向编译并重载受影响模块；失败可能升级为冷重启。

      正常路径保留应用 worker
      T2 / struct

      新增、删除或全量重载

      soft 范围中的路由、服务、中间件、Model 和语言资源发生增删时，重新扫描编译入口并更新运行态。

      重载受影响依赖图
      T3 / cold

      运行时边界冷启动

      配置、插件、预加载和启动依赖等边界改变时冷重启应用 worker；中间件通常仍属于 soft 范围。

      Performance Stack

      从 HTTP 处理到构建部署的框架能力。

      从路由、校验和类型契约开始，按应用需要启用前端、文档及运行功能，具体前提和限制见对应指南。

      fast path

      Native 高性能路径

      Native Adapter 贴近 Node.js 原生 HTTP，配合 route-core 路由核心保持轻量。

      router

      全栈路由核心

      文件路由、三段式路由定义、生成客户端契约和请求上下文围绕同一套 Vext 工程模型组织。

      schema

      校验与 OpenAPI

      在路由 options 中声明参数规则，让请求校验和接口文档共用同一份定义。

      cli

      开箱即用 CLI

      创建、开发、构建和启动命令收敛在框架入口，新项目可以直接开工。

      hooks

      运行时生命周期

      request、validation、response、service、fetch 等 hooks 支撑插件和横切逻辑。

      safe ship

      生产安全能力

      按需启用限流、结构化错误、优雅关闭和多进程监控，并在目标环境验证。

      Runtime Flexibility

      按集成需求选择 HTTP Adapter。

      Vext 的主线是框架自身的 API 性能与开发体验。Adapter 负责在需要时连接不同 HTTP 生态，让迁移和集成更稳。

      Native原生 HTTP fast path，适合追求极简依赖和吞吐。core
      Hono通过 Vext 自有 Node.js 桥接提供 Web Standard API；仅需 hono，且不是 Edge runtime adapter。lean
      Fastify成熟高性能生态，集成原生插件前需核对 Vext 的适配器边界。plugin
      Express迁移 Express 项目时需适配 Vext 请求与中间件合同。classic
      Koa支持洋葱模型；既有 Koa 中间件需核对接入方式。flow

      Production Operations

      按目标环境验证运行与部署能力。

      部署前核对功能开关、平台与超时预算，验证限流故障、关闭流程和 Worker 替换。配置支持不等于应用已经完成生产验收。

      Rate Limit默认关闭，显式启用后验证额度与存储故障。
      Graceful在关闭期限内等待请求与资源清理。
      Cluster多进程与心跳适合生产守护。
      Errors业务码、i18n 与 JSON-safe details。
